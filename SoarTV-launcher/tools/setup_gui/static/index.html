Google TV & Android TV (Sony, TCL, Xiaomi, Philips, Hisense, onn)
One-time 60-second debugging setup before your AI agent connects over Wi-Fi.
  1. Open TV Settings → System → About.
  2. Scroll to Android TV OS Build and press OK 7 times until "You are now a developer!" appears.
  3. Open System → Developer options and turn ON USB debugging (and Network debugging if shown).
  4. Read your TV's IP under Settings → Network & Internet → your Wi-Fi name.
Chromecast with Google TV / Android 14 Streamers
Uses Wireless Debugging pairing code before opening ADB port 5555.
  1. Enable Developer options as above, then open Wireless debugging and turn it ON.
  2. Select Pair device with pairing code and share the 6-digit code and IP:port with your AI agent.
LG webOS, Samsung Tizen & Amazon Fire TV
Quick platform-specific Developer Mode entry points.
  • LG webOS: Install Developer Mode from LG Content Store, enable Dev Mode Status + Key Server.
  • Samsung Tizen: Open Apps, press 1 2 3 4 5 on your remote, turn Developer mode ON with your PC IP, and reboot.
  • Amazon Fire TV: Settings → My Fire TV → About (click 7 times) → enable ADB Debugging.
Local Build Toolchain Inspection

What do I do manually vs. what does the AI agent handle?
You do manually: enable Developer Debugging on your TV once, create your free TMDB key, tap "Allow Debugging" on your TV screen, and (if using PC Gaming) install Sunshine. Your AI agent handles: cloning the repo, build tools, desk-monitor detection, TV brand safety checks, compiling, installing over Wi-Fi, and encrypting keys into Android KeyStore.
What if my AI agent fails to set an API key?
You can enter keys anytime directly on your TV inside SoarTV → Settings → Get Started (including QR Trakt pairing & WiZ Wi-Fi scan), or save them here and run python SoarTV-launcher/tools/send_key.py <TV_IP> --sync-config.
Can I add Gaming or Smart-Home tabs later?
Yes! Both features stay built in and cleanly hidden until needed. Turn them on anytime inside SoarTV → Settings → Home & Appearance → Interface & Units, or ask your AI agent to flip enable_gaming=true / enable_smarthome=true and sync keys.
Play Protect showed "Risky app blocked" on Android 14
Expected once for apps with a remote-button accessibility helper. Select More details → Install anyway on your TV remote. Always install over ADB rather than a TV file manager.
How do I return to my TV's original factory home screen?
SoarTV never deletes your stock launcher. Open SoarTV → Settings → System → Launcher Mode and select Original TV Home — your factory home returns immediately.
